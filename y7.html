公式与逻辑说明（释）

以下为输入区域各项目的计算公式、逻辑与相关设定，以及面板按钮的功能说明。
一、主统计（中列）
口 = 庄笔数 + 闲笔数（正数记庄、负数记闲）
口盈 = (盈 + 浮) ÷ 口
胜 = 庄 − 闲（净胜；庄多正、闲多负）
庄应多 = 口 × 1.36%（庄对闲的理论优势率）
胜率 = 庄 ÷ 口 × 100%
盈 = Σ 每笔盈换算（庄赢为5的倍数：0.95x−2.5；闲输负数：直接记 x）
均盈 = 盈 ÷ |胜|（结果为负时再 ÷0.95）
应均盈 = 盈 ÷ (庄应多 − 胜) ÷ 0.95（符号跟随盈）
期望赢 = (盈 − 口) ÷ 胜（结果为负时再 ÷0.95）
应期望赢 = (盈 − 口) ÷ (庄应多 − 胜) ÷ 0.95（符号跟随 盈−口）
码差 = 未抵消系统：按时间贪心抵消 + 全局最小差额配对；恒有 盈 = 码差 + 未抵消净额
洞 = Σ 每笔洞（庄赢：盈−洞基数；闲输：x+洞基数）
流水 = Σ |每笔注码|
二、今系列（右列，天清零点起，口径同上）
今口 = 今庄 + 今闲　今口盈 = 今盈 ÷ 今口
今胜 = 今庄 − 今闲　今庄应多 = 今口 × 1.36%
今胜率 = 今庄 ÷ 今口 × 100%　今盈 = Σ 天清零点后每笔盈
今均盈 = 今盈 ÷ |今胜|（负则 ÷0.95）
应今均盈 = 今盈 ÷ (今庄应多 − 今胜) ÷ 0.95（符号跟随今盈）
今期望赢 = (今盈 − 今口) ÷ 今胜（负则 ÷0.95）
应今期望赢 = (今盈 − 今口) ÷ (今庄应多 − 今胜) ÷ 0.95（符号跟随 今盈−今口）
今码差 / 今洞 / 今流水 = 今系列对应指标
三、左列与历史最值
本 = 用户设定的本金额度　余额 = 本 + 今盈
预均盈 / 预今均盈 = 输入框未确认时的预估
庄连 / 闲连 = 当前连续庄/闲的最大连数
庄最多 / 闲最多 = 庄/闲领先(庄−闲)的历史峰值
回撤 = 从庄领先峰值回落的深度
最盈 / 最亏 = 累计盈的历史最高 / 最低
庄 / 闲 = 庄/闲笔数　今庄多 / 今闲多 / 今撤 = 今系列对应最值

计算依据与提醒条件

EV=(1−佣金率)×P(庄胜)−P(闲胜)。绿色提醒直接按未四舍五入EV判断，不用“比新靴改善”或单看莊勝率。计算容差为每下注1单位1e-10，避免浮点零误报。相同佣金的新靴作为比较参照。5%佣金下，排除和局后的庄胜率须高于1/1.95才是正期望；佣金改变门槛随之改变。新靴移除A、2、3、4、0点牌通常改善EV，5–9通常变差；当前牌靴以即时重算为准。少于7张不算再移除效果，不足6张停止计算。提醒不自动下注。

假设剩余牌均匀随机、不放回。模型正期望不是下一局结果预测，不保证盈利。漏记、未知烧牌、连续洗牌、换靴未重置或特殊赔付会使模型与实况不符；和局退回庄注。
